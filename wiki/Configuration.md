# ⚙️ Configuration

Main config: `plugins/GrimML/config.yml`. `/grimml reload` applies changes.

| Section | What | Page |
|---------|------|------|
| `models` | Auto-update and manifest URL | [Updates](Updates) |
| `update-checker` | Plugin release notices | [Updates](Updates) |
| `window`, `scan` | ML scoring and fight judging | [How Scoring Works](How-Scoring-Works) |
| `aim-grid` | AimGrid tuning | [AimGrid](AimGrid) |
| `lunge-rate` | LungeRate tuning (cooldown shared by all swap checks) | [LungeRate](LungeRate) |
| `lunge-hold` | LungeHold tuning | [LungeHold](LungeHold) |
| `swap-order` | SwapOrder tuning | [SwapOrder](SwapOrder) |
| `axe-hold` | AxeHold tuning | [AxeHold](AxeHold) |
| `combo-repeat` | StunRepeat, SlamRepeat, WebRepeat | [WebRepeat](WebRepeat) |
| `alerts` | Format, hover, click command, sound, decay | [Alerts](Alerts) |
| `webhook` | Discord embed and punishment embed | [Discord Webhook](Discord-Webhook) |
| `punishments` | Groups, checks, commands per violation count | [Punishments](Punishments) |

Colours: `&` codes, `&#rrggbb` hex, or MiniMessage tags.
