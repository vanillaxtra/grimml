# session 2026-11-01b — mark-only mode + action bar feedback

## done

- added `recording-mode: auto|mark-only` config key; `PluginConfig.markOnly()` reads it
- `PlayerRingBuffer.markOnly` volatile; `markCombat()` returns early for non-marker triggers when true — events still write to ring so pre-buffer is intact
- `SessionRegistry.getOrCreate` stamps `buf.markOnly` from config on join
- `SessionRegistry.propagateMarkOnly(bool)` updates all live sessions; called by `ReloadCommand`
- `MarkTracker.allOpen()` returns live view of open segments
- `MarkFeedback` — main-thread runnable every 4 ticks; sends action bar to each marked player with:
  - colour-coded quality dot (green/yellow/red)
  - label + module
  - elapsed MM:SS
  - ping (green < 80, yellow < 180, red ≥ 180)
  - jitter (green < 30, yellow < 70)
  - server mspt (green < 15, yellow < 30)
  - frame count (green > 60, yellow > 20)
- task started in `onEnable` (4-tick interval), cancelled in `onDisable`
